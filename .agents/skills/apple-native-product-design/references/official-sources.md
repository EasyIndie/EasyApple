# 官方来源与刷新

参考核验日期：2026-10-13；不把本文件日期当未来最新状态。每次用户明确要求“最新”或平台大版本改变时，重新打开相关官方页。

- [HIG入口](https://developer.apple.com/design/human-interface-guidelines/)
- [Design Resources](https://developer.apple.com/design/resources/)：本次页面提供macOS27 UI Kit；系统字体/SF Symbols与图标模板来自官方，实际使用须遵守各自许可及系统可用性。
- [macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[iOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-ios)：输入设备、窗口、导航与平台差异。
- [Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)：动态语义、用户外观与自定义色的亮暗/高对比适配。
- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)：控制/导航材料与内容层区分，旧系统与辅助设置降级。
- [Menus](https://developer.apple.com/design/human-interface-guidelines/menus)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)：动作、标签、状态与字段身份。
- [Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：可读性、布局、替代信息与系统辅助功能。
